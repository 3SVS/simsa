# 빌더 벤치마크 #1 — 동네 미용실 예약 (사전 등록, 2026-10-05)

> 승인: Bae 2026-10-05 "어 다 그렇게 진행하자". 이 문서는 **어떤 앱도 만들기 전에** 커밋한다. 실행 뒤에는 고치지 않는다 — 바꿀 일이 생기면 [정정 날짜]로 덧붙인다.
> 왜: 1차 파일럿 7개 앱(intent-prompt-2026-10-04)은 Simsa 수정(#594)에 썼으므로 같은 앱으로 다시 재면 과적합을 가릴 수 없다. **새 주제·새 앱**으로 진단과 **수리까지** 기준을 잡는다.

## 1. 프롬프트 원문 (여섯 도구에 이 문장 그대로)

> 우리 동네 1인 미용실 예약 웹사이트를 만들어줘. 손님이 날짜와 시간(오전 10시부터 오후 7시까지, 30분 단위)을 고르고 이름과 휴대폰 번호를 넣으면 예약이 돼. 이미 예약된 시간은 다른 손님이 고를 수 없어야 해. 예약하면 예약 완료 화면에 예약 내용이 보이고, 새로고침해도 예약이 사라지지 않아야 해. 사장님은 관리 화면에서 오늘 예약 목록을 시간순으로 보고 예약을 취소할 수 있어. 가격은 커트 15,000원, 펌 60,000원처럼 원 단위로 보여줘. 휴대폰으로 보기 편하게, 모든 글은 한국어로 해줘.

도구: Lovable · v0 · Bolt · Claude · ChatGPT · Gemini (새 대화, 이전 맥락 없음).
**되묻는 질문에는 "알아서 판단해서 진행해줘"로만 답한다**(공정성). 질문 원문은 기록한다.
파일로만 주는 도구는 파일 이름을 `index.html`로 바꿔 공개 주소에 올린다(1차의 Gemini 404 교훈).

## 3. 절차

1. **제작(Bae)**: 위 문장 그대로, 되물음엔 정해진 답만.
2. **정답지(Claude)**: 실제 브라우저로 A1~A10을 하나씩 시험(한글 실데이터 — 예: 이름 "김민지", 번호 010-1234-5678, 같은 시간 두 번 예약 시도, 새로고침, 관리 화면, 취소 후 재예약, 390px). 앱별 `bench1-answer-key-<도구>.md`를 **Simsa 실행 전에** 커밋.
3. **진단(Simsa)**: 경로 (b) 주소만 · (c) 주소 + 의도(프롬프트 원문). 정답지와 대조.
4. **수리**: Simsa의 고침 지시를 **같은 빌더 대화에 그대로** 붙여 넣는다(최대 2회) → 재배포 → Simsa 재검사 + Claude 실브라우저 재확인(A1~A10).
