## 요약
- **문: (b) 만든 앱이 안 됨 — 한 브라우저 안에서만 작동하는 착시**. 손님끼리·손님과 사장님 사이에 예약이 공유되지 않아, 프롬프트의 "다른 손님이 고를 수 없어야", "사장님은 관리 화면에서 오늘 예약 목록"이 실제로는 성립하지 않는다. 추가로 KST 자정~09시 날짜 기본값 버그.
- **must 실패**: A3(다른 손님) · A6(사장님 기기) — 단일 브라우저 기준으로는 A2·A4·A5·A7 통과
- **기대 판정 (Simsa)**: **안 돼요 또는 사람 확인 필요**가 정답 쪽. 한 번의 브라우저 흐름만 보면 모든 것이 "된다"로 보이므로 Simsa가 **"문제를 찾지 못했어요"라고 하면 정반대 오판** — 두 번째 브라우저(저장소 비움)로 같은 시간을 확인해야 드러나는 유형. 서버 요청 0건이 단서.
- **예상 실패 지점**: 새 브라우저에서 이미 예약된 14:00이 비어 보임 · 사장님 관리 화면이 비어 있음 · 새벽 시간대 날짜 기본값이 어제.
