## 4. 원인 · 다음 고칠 것 (일반 규칙으로만)

1. **입력이 안 들어간다는 오판**(v0) — React 하이드레이션 오류(#418) 뒤 `fill` 타임아웃. 입력 재시도(한 글자씩)는 넣었으나 run-4에서도 실패 → 드라이버가 입력 대상을 잘못 고르는지(같은 이름 칸 2개 등) 계측 필요.
2. **"완료 화면 사라짐 = 저장 안 됨"으로 읽음**(Bolt) — 새로고침 뒤 **데이터**가 남는지(다른 화면·새 방문자)와 **완료 화면**이 남는지를 구분하는 지침 필요.
3. **시간대 결함**(v0·Bolt 관리 화면 UTC) — `set_clock`으로 00:30 KST를 재현하도록 지시했지만 실행기가 쓰지 않았다. 핵심 기준에서 시각 경계 탐침을 기본 단계로.
4. **Lovable 보류** — 핵심 기준이 비밀번호 화면을 만나면 "로그인 필요"로 전체를 보류한다. 공개 부분(예약 생성·공유·새로고침)만으로 통과 근거가 있으면 **공개 범위 통과 + 관리 화면은 확인 못 함**으로 나눠 말해야 정답("문제를 찾지 못했어요 — 관리 화면은 못 봄").
5. 시험 예약이 실제 앱에 남는다(C8 표지는 리포트에 기록) — Lovable은 run-2 뒤 시간대가 대부분 "마감"이 됐다. **6개 앱의 시험 예약 정리가 필요**(이름 김서연·이도윤·박지우 등, 번호 010-xxxx).
