## 운영 규칙 메모

- 모든 코드 stage: feature 브랜치 → PR → CI green → 별도 "PR #N merge approved." 후 squash 머지. main 직접 push 금지.
- 머지게이트 보고서는 로컬 checkpoint 브랜치에만 커밋(push 안 함) → merge queue 깨끗 유지.

- 승인 문구는 **정확·독립·비전이**. PR merge 승인 ≠ install/apply/wiring/deploy. 스테이지 프롬프트 내 조건 인용 ≠ 직접 부여.
