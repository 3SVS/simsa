## 3. 확정된 원인

- **central Worker는 같은 CF 계정의 workers.dev 픽스처를 못 읽는다** (`simsa-inspection-fixtures.seunghunbae.workers.dev` → Worker에서 404, 노트북에서 200).
  - 영향: 프로덕션에서 픽스처의 의도 추론·dev-spec 웹 증거는 늘 빈다. 검사 자체는 컨테이너라 영향 없음.
  - 수정 후보: 픽스처를 다른 계정/도메인으로 옮기기(추천) · `global_fetch_strictly_public`(모든 fetch에 영향, 회귀 확인 필요).
- **라벨러 상태 버그(#629로 수정)**: 테스트 모크만 KV를 제공했고 프로덕션엔 바인딩이 없었다. 모크 모양 ≠ 프로덕션 모양.
