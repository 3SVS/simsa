> **한 줄 요약:** **Simsa의 모든 사용자 접점**(대시보드 16개 라우트 + 랜딩 서브페이지 + simsa-dev +
> 이메일/OG/파비콘/에러 페이지)을 #244 랜딩의 디자인 언어(인장 브랜드 · 필 버튼 · 카드 그림자 ·
> Pretendard · 모션)로 정렬한다. 감사 방법 §0, 화면별 지시 §4, 대시보드 외 표면 §4-b.

## 0. 감사 방법 (재현 가능)

헤드리스 크로미엄(깨끗한 프로필, KO 모드, 1280×850)으로 아래 16개 라우트 전수 캡처 후 육안 감사:
`/projects` `/projects/new` `/projects/new/intake` + 예시 프로젝트(proj_mjx1)의
`{overview, idea, spec, items, settings, github, checks, visual-checks, fixes, export, sources}` + `/account` `/login`

## 1. 글로벌 — 디자인 시스템 이식 (랜딩 → 대시보드)

1. **폰트**: 랜딩과 동일하게 **Pretendard Variable**(CDN dynamic subset)을 한글 우선으로 추가.
   현재 Geist 단독이라 한글이 시스템 폴백으로 떨어져 랜딩과 이질감. font-family:
   `Geist(영문/숫자) → Pretendard(한글)` 순 정렬.
2. **브랜드 마크**: 사이드바 상단 `○ Simsa`(골드 링) → **전각 인장 마크 + Simsa** (랜딩 `StampMark`
   클린 버전 26px 이식 — 공용 컴포넌트로 추출해서 랜딩/대시보드 공유. 파비콘도 교체).
3. **버튼**: 랜딩 문법으로 통일 — **필(999px) 형태**, 주인공 1개/화면(oxblood 채움 + CTA 그림자),
   세컨더리 = 조용한 필(#f1eee8류), #238의 5-상태(hover/active scale 0.97/disabled/loading) 유지.
   **disabled 스타일 규칙 필수**: 현재 intake CTA가 탁한 분홍으로 "죽은 버튼"처럼 보임 →
   `opacity 0.45 + cursor-not-allowed` + 비활성 사유 헬퍼 텍스트.
4. **카드**: 1px 보더 단독 → 랜딩 `--shadow-card`(링+컨택트+앰비언트) 통일. 선택형 카드는
   hover 리프트(translateY -2px + shadow-float) + active 프레스.
5. **배경**: 본문 캔버스에 랜딩의 초미세 앰비언트(상단 4% 틴트 그라데이션)만 이식. 입자 필드는
   앱에는 금지(작업 화면 소음).
6. **언어 토글(EN/KO)**: 우상단 부유 텍스트 → 랜딩 `lang-toggle` 스타일(조용한 필)로 통일.
7. **깨진 글리프 전수 수정**: `/projects/new` 선택 카드 제목 앞 □(tofu) — 이모지/미로딩 아이콘.
   이모지 금지 원칙대로 **랜딩 start-grid 라인 글리프 SVG**(전구/문서/링크 등, 틴트 사각) 재사용.
   `rg`로 동일 이모지 사용처 전수 검색해 같은 커밋에서 수정.

## 2. 공용 프리미티브 (1차 PR 스코프)

- `packages/` 아님 — `apps/dashboard/src/components/brand/` 에 `StampMark`(랜딩과 동일 SVG),
  `apps/dashboard` globals.css에 버튼/카드/토글 토큰 반영.
- 랜딩 CSS를 그대로 복붙하지 말 것 — 대시보드 기존 `.btn` 계열/Tailwind 토큰(brand=oxblood) 위에
  **형태(필)·그림자·상태**만 덧입힌다.

## 3. 화면 밀도 원칙

랜딩은 마케팅 스케일(큰 타입), 앱은 작업 도구 — **타입 스케일은 키우지 않는다.**
가져오는 건 색·형태·그림자·모션·브랜드 마크. 히어로형 대문짝 타이포 금지.

## 4. 화면별 지시 (감사 결과)

### P0 — 첫인상 경로
- **`/projects/new` (3-선택)**: ① 제목 앞 □ 깨진 글리프 → 라인 글리프(§1-7). ② 3개 동일 플랫 카드
  → 글리프+틴트로 차별화, hover 리프트, 카드 폭 축소(max-w 34rem) + **세로 중앙 정렬**(현재 상단
  몰림 + 하단 거대 여백). ③ 좌상단 붉은 진행바 조각(스크롤 아티팩트) 원인 확인.
- **`/projects/new/intake` (기획서 붙여넣기)**: ① CTA disabled가 탁한 분홍 → §1-3 규칙.
  ② placeholder 모노스페이스 → 본문 폰트. ③ "← 세 가지 선택으로" 버튼 → 조용한 텍스트 링크 스타일.
  ④ textarea 포커스 링(brand 틴트) + 카드 그림자. ⑤ 빈 공간 과다 — 콘텐츠 세로 중앙.
- **`/login`**: ① **비개발자 타겟인데 GitHub 버튼이 최상단 주인공** → 순서: Google(시크릿 설정 시)
  > 이메일/비번 > GitHub(하단 조용히, 개발자용 라벨). ② "로그인" 제출 버튼이 세컨더리 흰색 →
  주인공 oxblood 필. ③ 인장 마크 + 카드형 집중 레이아웃(로그인 중 사이드바 숨김 검토).
  ④ "나중에 하기" 익명 경로는 그대로 유지 (좋음).
- **`/projects` (홈)**: 예시 카드에 hover 리프트, "+ 새 프로젝트" CTA를 주인공 필로. 빈 상태 점선
  박스 → 카드+글리프.

## 4-b. 대시보드 외 전 표면 (Bae 지시로 확대 — 2026-07-06)

### 랜딩 서브페이지 (`apps/simsa-landing`)
- **`/demo`**: `.demo-card`/`.kv`/`.ev-*`는 팔레트만 정렬된 상태 — 랜딩 본편과 동일한 **내비(플로팅
  글래스 필) + 푸터(인장 마크)**를 붙이고, 판정 블록(`.decision`)에 인장 프레스 소형 모션(선택) 적용.
- **`/privacy` · `/terms`**: 동일 내비/푸터 공유, `.back` 링크를 랜딩 텍스트 링크 스타일로. 본문
  타이포 Pretendard 정렬.
- 서브페이지 3곳 모두 hero급 스케일 금지 — 문서 페이지 밀도 유지.

### simsa-dev (`apps/simsa-dev`, 개발자 플레이스홀더)
- 구버전 그린/카드 스타일 잔존 — 새 시스템의 **미니 버전**으로 교체: 인장 마크 + oxblood 필 CTA +
  파치먼트 배경 + Pretendard. 단일 카드 구조는 유지(플레이스홀더 성격 그대로).

### 공통 자산 (전 표면 일괄)
- **파비콘/앱 아이콘**: 전각 인장 마크로 통일 — landing·dashboard·simsa-dev 3개 앱 전부.
  (SVG → ico/png 파생, 32/180/512.)
- **OG 이미지**: 인장 + 워드마크 + 태그라인 1장 제작, 3개 앱 metadata에 공통 적용
  (KakaoTalk/Threads 링크 프리뷰가 KO-first 배포 채널이므로 필수).
- **트랜잭션 이메일 템플릿** (D2 인증 메일, 피드백 관리자 통지): 플레인 텍스트에 최소 브랜드 —
  상단 인장 마크(72px png) + oxblood 링크 색. 과한 HTML 메일 금지(스팸 점수·다크모드 반전 리스크).
- **404/에러 페이지**: landing·dashboard 각각 — 인장 마크 + "돌아가기" 주인공 버튼 1개.
  (현재 Next 기본 404일 가능성 — 확인 후 없으면 추가.)
- **FeedbackModal**(대시보드): 필 버튼·카드 그림자 정렬 (§1 규칙 자동 적용 확인만).
