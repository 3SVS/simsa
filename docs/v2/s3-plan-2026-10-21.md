## 무엇
- `src/v2-plan.ts` — 정적 사실(S2 증거물 id 포함) + 확인된 기준(AC)으로 **가설과 확인 실험 계획을 결정론으로** 만든다(LLM 0, 같은 입력 → 같은 계획). 근거 없는 가설은 만들지 않는다(증거물 id 없는 사실·모르는 분류 제외).

| 사실(S2) | 가설 | 확인 실험 | 덮는 기준 |
|---|---|---|---|
| R1 백엔드 미설정 | 결과가 저장되지 않는다 | `submit_and_probe` | 기록을 만드는 기준(전제가 기록 · 제출해 긍정 결과 — 형식 거절 확인 제외) |
| R2 기기에만 저장 | 다른 손님·사장님은 못 본다 | `fresh_browser_lookup` | 다른 손님·관리 화면 기준 |
| R3 UTC 날짜 | 한국 새벽엔 '오늘'이 하루 전 | `clock_early_morning_kst`(실행기 시계 변형 — 언제든) | 오늘·관리 화면·날짜/시간 목록 기준 |
| R5 서버 렌더 날짜 | 서버가 UTC로 '오늘' 계산 | `real_time_window_kst` **[0,9)** — 기기 시계로는 서버를 못 속인다 → 낮엔 `runnableNow=false` | 같음 |
| R4 사용자 API 키 | 키 없이는 시작 불가 | `human_key_required` | must 전부 |

- 계획은 증거물(kind `context`)로 저장·되읽기(재검사가 같은 계획을 쓴다). 원문 상한을 넘으면 조용히 자르지 않고 실패(`plan_too_large`).
- `src/ac-semantics.ts` — AC 선행 조건 판단(`classifyPrecondition`) **단일 출처**. PR #609(머지 전)의 같은 함수를 복사하지 않으려고 먼저 main에 둔다 — #609는 머지 때 이것을 가져다 쓴다.
