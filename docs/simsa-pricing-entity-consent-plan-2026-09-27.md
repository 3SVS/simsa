## 0. 결론

- **과금 도입 비용은 작고(일회성 ≈ $1.1K 개발 + Paddle $0 + 법무·세무 $0.5K~2.4K[미검증]), 12개월 매출 효과는 그보다 작다**(D3 ≈ $50, D2 ≈ $1.8K). 도입 근거는 매출이 아니라 ①카드 등록률·WTP·환불·분쟁의 실측 장비 ②"돈 받는 제품" 서사(D-13)다. 이 전제를 결정 문서 첫 줄에 쓴다.
- **성공 시 청구(works-or-free)는 Paddle에서 성립한다**[확정]: 결제수단 수집형 $0 트라이얼 구독 → 성공 판정 시 `POST /subscriptions/{id}/charge`(trialing 상태 일회 청구는 공식 문서화). auth hold는 없고, "선결제+자동 환불"은 실패율(D3 80%)이 곧 환불률이 되어 폐기한다.
- **가격**: 첫 유료 SKU = **수리 초과 $29**[PILOT](월 무료 3회 소진 후, 재검수 통과 시만). 빌드 works-or-free는 **표시가 $199**[PILOT]로 잠그고 파일럿 (a) 실측 뒤 D-22 공식으로 $149 회귀 여부 판정(내리기는 쉽고 올리기는 어렵다). Care $19/앱·월은 M6+로 미룸. 검수 API $0.20/회·월 최소 $50(B2B 인보이스).
- **정직한 한계**: D3(Floor) 가정에서 어느 SKU도 총마진 60%를 못 넘긴다. 지배 변수는 LLM 원가가 아니라 **건당 사람 지원 시간**(D3 30분 가정 = $12.5)과 **빌드 원가 상한 집행 여부**(지금 코드는 상한을 집행하지 못한다)다. 즉 가격표보다 먼저 ①L0 계측·B6 예산 정지 ②셀프서브(지원 ≤ 7분) 설계가 마진을 결정한다.
- **청구 주체**: **오마이워크(현행 약관 명의)로 지금 Paddle 개통**, 신설 한국 법인 전환 트리거를 미리 잠그고, 미국 C-Corp은 YC 합격·미국 리드 투자 시점에만. 3SVS 법인은 청구 주체로 쓰지 않는다(YC 경로에서 분리 비용이 이연될 뿐 사라지지 않음). 단 IP 양도 서면(3SVS → Simsa 사업 주체)은 어느 안이든 필요.
- **동의 정책**: ⓐ 비식별 운영 메타 = 고지 + 이의(끄기) 토글(정당한 이익), 단 EU/UK 유저는 ePrivacy 5(3) 때문에 ⓐ도 opt-in; ⓑ 내용 데이터 = 대칭 opt-in(기본 OFF, 동등 버튼, 인센티브 없음). 현재 코드는 ⓐ를 **고지 없이 기록 중**이고 ⓑ 거절이 저장되지 않아 재초대되는 결함이 있다 → 파일럿 첫 행 전에 고친다.
- **개발 계획**: 파일럿을 (b)(c) 3건(10/11 목표, 인도 경로 라이브)과 (a) 3건(10/25 목표, B5(b) 필요)으로 분할. 7개 트레인 ≈ 51 에이전트-일, 에이전트 2~3 병렬로 6주. 과금 라이브 첫 실청구는 Paddle 승인이 오는 W6 이후.

### 2.7 파일럿에서 가격 신호를 얻는 법

n=6은 가격 판별 불가[확정 계산: 6/6 성공도 Wilson 하한 61%, 0/6이면 45% 가정만 기각]. 파일럿의 가격 산출물은 결정이 아니라 **장비 6개 설치·검증 + 판정 규칙 사전 등록**이다.
1. 퍼널 7이벤트: dev_spec_completed → price_shown(variant, locale) → checkout_opened → card_saved → build_started → build_done → charged | trial_cancelled.
2. 가격 표시 실험은 A/B 아닌 **카피 2종**(금액 고정): "빌드 $199 (성공 시만)" vs "$0 — 검수 통과 시에만 $199 청구". 검출 대상 = 결제 화면 진입률.
3. real ask 1회: 6건 각각 샌드박스 카드 수집 체크아웃 + 조건부 청구 동의 화면을 실제로 통과(내부 6건 = 장비 검증, 외부 첫 6명 = 등록률 신호).
4. WTP 인터뷰(성공 사례만): Van Westendorp 4문항 기록(교차점 산출 안 함) + Gabor-Granger 사다리($49→$99→$149→$199→$299).
5. support_minutes·이의(생각과 다름)·재작업 수기 시트.
6. 판정 규칙 사전 등록: 빌드 0/6 → S1 보류 · support 중앙값 > 15분 → S2 $39 · 결제 화면 진입 < 10% → 가격 아닌 유입 문제로 분류 등 5개.
