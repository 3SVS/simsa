## 0. 한 줄

데이터셋의 한 행 = **(비개발자의 의도) → (사용자가 확인한 기준들) → (기준별 기계 판정 + 증거) → (기준별 사람 판정) → (사용자의 최종 수용)**. 이 다섯 칸이 모두 찬 행만 "벤치마크 등급"이다. 지금 코드는 셋째·다섯째 칸을 이미 기록하고, 넷째 칸(독립된 사람 판정)이 없다.

## 2. 사람 판정(라벨링) 규약

**원칙: 기계 판정을 보기 전에 사람이 먼저 본다.** 기계 판정을 보고 라벨을 달면 기계와 사람의 일치율이 부풀려져 측정 자체가 무의미해진다.

1. **라벨러:** v0 = Bae 1명 + 두 번째 라벨러 1명 [결정: 누구 — 3SVS 구성원 또는 외부 1명]. 두 번째 라벨러는 전체의 **20% 이상**을 독립적으로 이중 라벨링한다.
2. **절차(AC 하나당):** 앱 주소와 AC 문장만 보고 직접 조작 → 판정 3택(pass / fail / cannot_verify) → fail이면 결함 분류 1개 → 1줄 메모. 소요 목표 AC당 2분 이내 [추정].
3. **판정 기준(루브릭):** 10-06 진단 H1 원칙을 사람에게도 똑같이 적용한다 — "사용자가 그 결과를 **얻을 수 없을 때만** fail. 화면 구성·순서는 fail이 아니다." 경계 사례는 `docs/dataset/rubric-examples.md`[신규]에 사례로 쌓는다(규칙보다 사례가 라벨러를 맞춘다).
4. **일치도:** 이중 라벨 구간에서 Cohen's κ를 낸다. **κ ≥ 0.7 미만이면 루브릭을 고치고 그 구간을 다시 라벨링**한다(데이터셋 공개 전 조건). 불일치 건은 제3자(또는 Bae) 판정으로 확정하고 원래 두 라벨도 보관한다.
5. **도구:** 별도 앱을 만들지 않는다. v0은 스프레드시트 한 장(행 = 런×AC, 기계 판정 열은 숨김)으로 시작한다 [YAGNI]. 100행이 넘으면 대시보드 관리 화면에 숨김 열 라벨링 뷰를 만든다 [신규, 나중].
6. **기록 위치:** 사람 판정은 **저장소 밖**(비공개)에 둔다. 저장소에는 해시와 집계만(`docs/simsa-index-design-2026-10-18.md` §3 사전 등록).
7. **장비 의심 플래그:** 특정 빌더(또는 특정 앱)에서만 나는 fail은 데이터셋·지수에 넣기 전 `equipment_suspect=true`로 표시하고 **사람이 직접 재현해 확인**한 뒤에만 fail로 확정한다. 근거: 2026-10-19 발견 — 검사 드라이버가 `confirm()` 대화상자를 전부 dismiss해 confirm을 쓰는 앱(bolt·gemini)에서 "취소가 안 된다"는 fail이 앱 결함이 아니라 측정 장비 결함이었다(격차 목록 §7). 확인 전 fail은 라벨 시트에서 `pending_equipment_check`로 둔다.

## 5. 분석 계획 — 데이터를 보기 전에 등록한다

데이터를 본 뒤 지표를 고르면 원하는 결론을 고르게 된다. 아래를 첫 라벨 전에 커밋한다(EVIDENCE-RULE R8).

**1차 지표(공개용)**
1. **심판 정확도:** AC 단위 기계↔사람 일치율 + κ. 혼동행렬(특히 기계 pass / 사람 fail = 거짓 통과). 이 숫자가 공개 기준이 못 넘으면 다른 숫자는 공개하지 않는다.
2. **빌더 × 연동 실패율:** (사람 판정 기준) must AC 실패 비율, 셀별 95% 신뢰구간. 한국 연동 vs 글로벌 연동 쌍의 차이.
3. **의도 불일치율:** ⑥에서 works_but_different 비율 — "작동하지만 원한 게 아니다". 기존 벤치마크가 못 재는 축.
4. **포템킨 비율:** 결함 중 포템킨형 비중.

**2차 지표(내부)**
- 수리 뒤 해결률(resolved=1) · 같은 앱 재검수 판정 일치율(재현성) · 런당 비용.

**표본 크기 현실 [추정]:** 실패율을 셀별 ±10%p(95%)로 말하려면 셀당 약 100개 앱이 필요하다. 빌더 4 × 연동 쌍 3 = 12셀이면 1,200개. **v0 공개는 셀을 합쳐서**(빌더별 또는 연동별 한 축만) 말하고, 셀별 표는 표본이 찰 때까지 "표본 n"과 함께만 낸다. 작은 셀에서 순위를 매기지 않는다.
