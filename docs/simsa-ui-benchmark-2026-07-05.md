# 지시서 — Simsa UI 벤치마크 + 인터랙션 상태 스펙 (2026-07-05)

> **한 줄 요약:** Simsa가 못생겨 보이는 1차 원인은 색·레이아웃이 아니라 **인터랙션 상태 부재**다.
> `.btn`에 hover만 있고 active/disabled/loading이 없고, 툴팁·토스트 시스템이 없다 (globals.css 확인됨).
> 레퍼런스 5곳에서 차용할 요소를 화면별로 명시한다.

## 0. 레퍼런스 선정 (Simsa와 겹치는 축 기준)

| 레퍼런스 | 겹치는 축 | 가져올 것 |
|---|---|---|
| **Linear** | SaaS 광택의 기준 | 밀도·마이크로 인터랙션·키보드 UX·상태 아이콘 |
| **Vercel (Geist)** | 라이트 테마 + **이미 Geist 폰트 사용 중** — 자연스러운 짝 | 버튼 5-상태 스펙·스켈레톤·배지·배포 상태 점 |
| **Lovable / v0** | 동일 타겟(바이브코더 비개발자) | 큰 CTA·스텝퍼·진행 중 스토리텔링·성공 연출 |
| **CodeRabbit / Graphite** | 동일 기능(리뷰 리포트) | 판정 배너·심각도 칩·접이식 finding 카드 |
| **토스(Toss)** | 한국 비개발자 톤의 기준 | 눌림 촉감(press scale)·화면당 한 가지·쉬운 카피 |

---

## 1. ★ 버튼 — 5-상태 전부 구현 (지금 hover만 있음)

Geist/Linear 공통 스펙. `globals.css`의 `.btn` 계열에 추가:

```css
.btn {
  /* 기존 + */
  transition: background-color 120ms ease, transform 100ms ease, box-shadow 120ms ease;
  user-select: none;
}
/* ① 눌림 — 즉각 촉감 (토스/Linear 패턴) */
.btn:active:not(:disabled) { transform: scale(0.97); }
.btn-primary:active:not(:disabled) { @apply bg-brand-800; }
.btn-secondary:active:not(:disabled) { @apply bg-gray-100; }
/* ② 비활성 — 왜 안 눌리는지 보이게 */
.btn:disabled { @apply cursor-not-allowed opacity-50; }
/* ③ 주인공 버튼 가시성 — 평면 단색 탈피 (3-레이어 쉐도우, design-tokens 기준) */
.btn-primary {
  box-shadow: inset 0 1px 0 rgb(255 255 255 / 0.12),  /* top highlight */
              0 1px 2px rgb(0 0 0 / 0.08),              /* contact */
              0 2px 6px rgb(0 0 0 / 0.06);               /* ambient */
}
.btn-primary:hover { box-shadow: /* ambient 강화 */ 0 3px 10px rgb(0 0 0 / 0.10), 0 1px 2px rgb(0 0 0 / 0.08); }
```

- **로딩 상태**: 라벨 교체("보내는 중…")만으로 부족 — 인라인 스피너(14px, currentColor) + 버튼 폭 고정
  (라벨 길이 변화로 레이아웃 점프 금지). 공용 `<Spinner/>` 하나 만들어 전 화면 재사용.
- **최소 타깃**: 주요 CTA min-height 40px(모바일 44px). 텍스트 링크형 액션(재실행 등)은 버튼으로 승격
  (ux-sweep P2-10과 동일 건).

## 2. ★ 툴팁/대화풍선 — 시스템 자체가 없음

- 공용 `<Tooltip/>` 도입 (Radix `@radix-ui/react-tooltip` 권장 — shadcn 조합, 접근성 공짜).
- **적용 원칙 (Linear):** 아이콘-온리 컨트롤 전부 필수 — 사이드바 ＋/▦/«, 복사·새로고침·닫기 ×.
  텍스트 라벨 있는 버튼에는 달지 않는다 (소음).
- delay 300ms, 위치 자동 플립, 키보드 포커스에도 표시.
- 클릭 결과 안내가 필요한 곳(예: "복사됨")은 툴팁이 아니라 ↓토스트 또는 버튼 라벨 순간 교체("✓ 복사됨" 1.5s).

## 3. ★ 토스트/성공 피드백 — 액션의 결과가 화면에 없음

- 공용 `<Toast/>` 1개 (우하단, 3초, 성공/실패 2변형). 인라인 callout은 폼 검증용으로만 유지.
- 적용: 저장/전송/복사/연결 성공, `.catch(() => undefined)`로 숨던 서버 동기화 실패(ux-sweep P1-5)의
  "서버 저장 실패 — 기기에는 저장됨" 배너.
- Linear 패턴: 파괴적이지 않은 액션은 확인 다이얼로그 대신 **토스트 + Undo**.

## 4. 검수 결과 화면 — CodeRabbit/Graphite 차용 (checks "3초 파악"과 연결)

1. 최상단 **판정 배너**: 통과=green/실패=red 한 줄 + 요약 숫자("12개 중 9개 통과"). 아이콘+색+텍스트 3중 인코딩(색맹 대응).
2. finding = **접이식 카드**: 접힌 상태 = 심각도 칩(P0 red/P1 amber/P2 gray) + 제목 한 줄. 펼치면 무엇이/왜/어떻게 + 증거 스크린샷.
3. 심각도 칩은 채운 배경이 아니라 **틴트 배경 + 진한 텍스트** (red-50/red-700) — 리포트가 경고등 크리스마스트리 되는 것 방지.
4. 진행 중 상태는 Vercel 배포 점 패턴: ● pulse 애니메이션 + "확인 중… (2/5 화면)" 카운터.

## 5. 플로우/위저드 — Lovable·토스 차용 (new/intake)

- 스텝퍼: 현재 2px 프로그레스 바 → **라벨 있는 단계 표시**("1 아이디어 → 2 확인 → 3 질문 → 4 완성", 현재 단계 강조).
- 긴 대기(LLM 생성 중): 스피너만 X → 단계별 상태 텍스트 로테이션("아이디어를 읽고 있어요 → 화면 흐름을 그리고 있어요") — Lovable의 진행 스토리텔링.
- 완료 화면: 성공 연출 한 번(체크 아이콘 스케일-인 200ms) + 다음 행동 1개만 제시(토스: 화면당 한 가지).

## 6. 표면 광택 — Linear/Geist 소소한 것들 (AI slop 금지 준수)

- 카드: `border-gray-200` 단독 → + `shadow-[0_1px_2px_rgb(0_0_0/0.04)]` (붕 뜨지 않는 접촉 그림자).
- 사이드바 활성 항목: 배경색만 → + 좌측 2px 인디케이터 또는 아이콘 색 전환 (1px 초과 스트라이프 금지 규칙 내에서).
- 상태 점(● 초록/노랑/빨강)을 프로젝트 카드·검수 카드에 일관 사용 — Vercel 배포 상태 문법.
- 빈 상태: 텍스트만 X → 작은 일러스트/아이콘 + 한 줄 + CTA 1개.
- 테이블/리스트 hover: `hover:bg-gray-50` 전 행 통일.
- Cmd+K 커맨드 팔레트는 §7 Lvl 2 이후로 (지금 금지 — YAGNI).

## 6-b. ★ 방향 확정 (2026-07-05, Bae): **화이트 기본 유지 — "Linear의 라이트 버전"**

다크 전환 안 함. Linear/Discord에서는 **버튼 모양·UX·이펙트(인터랙션 언어)만** 가져온다.
최신형 라이트 레퍼런스 추가: **Slack, Notion, Luma(lu.ma)**.

| 레퍼런스 (라이트) | 가져올 요소 |
|---|---|
| **Linear light** | 1px 크리스프 보더, 6-8px radius, 컴팩트 밀도(13-14px), 100-150ms 빠른 트랜지션, hover 틴트, 아이콘 버튼 툴팁+단축키 힌트 |
| **Notion** | 콘텐츠가 주인공인 조용한 크롬, **호버 시 컨트롤 노출**(행 위 ⋯/복제/삭제), 미니멀 툴바 |
| **Slack** | 또렷한 주인공 버튼(채운 배경+굵은 라벨), 명확한 focus 상태, 친근한 빈 상태(일러스트+한 줄+CTA) |
| **Luma** | 부드러운 멀티레이어 쉐도우, 넉넉한 radius 카드, **눌림 이펙트의 촉감**(press scale+그림자 수축), 절제된 파스텔 포인트 |
| Discord | 구조 아님 — 호버 반응 속도감, 상태 점 문법만 |

배경은 현 #faf8f3 웜 화이트 유지 (Luma 계열과 정합). 브랜드 컬러 유지.
