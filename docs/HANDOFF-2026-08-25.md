## 1. 무엇이 바뀌었나 — 첫 화면이 여섯 칸에서 한 칸으로

Bae 지적: *"앱을 만들어서 검수를 받아보고 싶은 사람도 제품설명·깃헙 연결·url 연결·
데이터베이스 연결을 다 지나가야 해?"*

실측 결과 **하드 게이트는 앱 이름 하나뿐**이었지만, 문제는 필수 여부가 아니라
**사용자가 손에 들고 온 것(앱 주소·저장소)을 첫 화면에서 묻지 않는 순서**였다.

```
전: 갈래선택 → [이름*·빌더·호스팅·데이터·설명·필수동작] → 연결화면 → 소스추가 → 검수
후: 갈래선택 → [주소 또는 저장소*] → 즉시 검수 + 의도 추론 → "맞나요?" 확인 → 정밀 검수
```

정본 설계 = `docs/simsa-artifact-first-entry-design-2026-08-23.md` (D-1~D-10).

## 4. ★#504가 AF 트레인보다 중요하다

Anthropic은 마지막 메시지가 assistant면 **그 뒤를 이어서** 쓴다. `generate.ts`는
`{`를 prefill로 주고 응답 앞에 되붙인다. OpenAI는 **완전한 JSON**을 주므로 되붙이면
`{{…}` → 파싱 실패.

즉 **Anthropic이 차단된 이후 스펙 생성이 전 갈래에서 조용히 실패하고 있었다.**
prefill을 안 쓰는 검수·수정·추천은 멀쩡했기에 드러나지 않았다.
`rg 'role: "assistant"'` 전수 검색 결과 prefill 사용처는 `generate.ts` 한 곳뿐.

**아이디어 갈래·스펙 갈래도 이 경로를 쓴다 — 그쪽 라이브 확인은 아직 안 했다.**
다음 세션 우선 확인 대상.

## 5. 방법론 기록 (반복하지 않기 위해)

- 세 결함 모두 **API 프로브로는 안 보였다.** 응답은 전부 200이었고 폴백도 "성공"으로
  로그에 남았다. **실제 여정을 브라우저로 걸어야** 드러났다.
- #504는 가설을 두 번 틀린 뒤에야 잡혔다(절단 → 아님). 오진의 원인은 진단이
  `head: {{` 두 글자에서 잘려 있었던 것. **읽히지 않는 계측은 없는 계측과 같다.**
- 감사 장비(journey-audit) 자체가 **옛 화면을 전제로** 짜여 있었다. 제품을 바꾸면
  측정 장비부터 맞춰야 한다.
- Rule 6: 근거 판정 임계 30자가 *"주말 티타임을 찾아주는 서비스입니다"*(19자)를
  버렸다. **영어 기준 임계가 한국어를 차별한다.** 15자로 조정.
- 플레이키 테스트 1건 제거 — 403 재시도가 난수 미주입으로 확률적으로 깨졌다
  (며칠 전 "재현 안 됨"으로 넘긴 그 실패). 원인은 stale dist가 아니었다.
